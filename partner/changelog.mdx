Mudanças relevantes ao contrato externo da API de Parceiros são registradas
aqui, em ordem cronológica reversa (mais recente no topo).

<Note>
  Este changelog é mantido **manualmente**. Toda vez que um endpoint público
  mudar de contrato, abra um PR neste repositório atualizando esta página.
</Note>

## Convenções

- **Added** — endpoints, campos ou comportamentos novos.
- **Changed** — alterações compatíveis (não-breaking).
- **Deprecated** — algo ainda funciona, mas será removido em uma data futura.
- **Removed** — ⚠️ **BREAKING** — algo deixou de existir.
- **Fixed** — correções de bugs no contrato (ex.: schema que não refletia a resposta real).
