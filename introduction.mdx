  <Card

  <Card
    title="API de Backoffice"

    mas voltada exclusivamente a times internos.
  </Card>

## Como usar esta documentação

Cada API tem seu próprio dropdown no menu superior, com:

- **Documentação** — guias conceituais, autenticação, quickstart e changelog escritos à mão.
- **Referência da API** — gerada automaticamente a partir do OpenAPI de cada BFF.

<Note>
  Não confunda com o `bff-app` (usado pelo aplicativo mobile da Robbin). Esse BFF
  **não** é documentado aqui.
</Note>

## Suporte

- Parceiros: entrem em contato com seu gerente de integração na Robbin.
- Times internos: usem o canal `#api-platform` no Slack.
